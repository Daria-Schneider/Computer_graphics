# Лабораторная работа №2. Камера и освещение

Вариант 3: параллелепипед. Выполнены базовое задание и все дополнительные задания 1-4.

Проект сделан на основе кода первой лабораторной работы и стартового кода https://github.com/vladeemerr/vulkan-starter-app (Vulkan, GLFW, ImGui).

## Что умеет программа

- рисует сцену из параллелепипедов: параллелепипед по варианту, пол, наклонный параллелепипед и колонну
- свободная камера: позиция, поворот (азимут и наклон), угол обзора, ближняя и дальняя плоскости
- освещение по модели Блинна-Фонга во фрагментном шейдере: фоновый свет, один направленный источник, массив точечных источников и массив прожекторов
- у точечных источников и прожекторов затухание по закону обратных квадратов
- у прожектора мягкий край между внутренним и внешним углом, если углы равны, край резкий
- точечные источники и прожекторы можно добавлять, удалять, включать и выключать, любой прожектор можно прикрепить к камере как фонарик
- у каждого объекта меняются форма, положение, поворот, растяжение, вращение и материал: альбедо, цвет блика, коэффициент блика
- нормали вершин считаются процедурно: нормаль грани это векторное произведение её рёбер
- источники света видны на сцене: точечные источники и прожекторы рисуются кубиками своего цвета, у прожектора белыми линиями нарисованы ось и конус внешнего угла, серой окружностью внутренний угол; эти фигуры не освещаются, их можно скрыть флажками

## Как устроены данные для шейдеров

Набор дескрипторов 0 (сцена, общий для всех объектов):
- binding 0: uniform-буфер SceneData, в нём матрица view-projection, позиция камеры, фоновый свет и направленный источник
- binding 1: storage-буфер с точечными источниками
- binding 2: storage-буфер с прожекторами

Набор дескрипторов 1 (модель, у каждого объекта свой):
- binding 0: uniform-буфер ModelData, в нём матрица модели, матрица нормалей и материал

В начале каждого storage-буфера записано количество источников, за ним идёт массив. В шейдере размер массива не указан.
Если источников становится больше, чем помещается в буфер, программа создаёт новый буфер в два раза больше и обновляет дескриптор.

Фигуры визуализации источников строятся каждый кадр на процессоре сразу в мировых координатах и записываются в отдельный вершинный буфер.
Они рисуются двумя отдельными конвейерами (кубики треугольниками, конусы отрезками) с шейдерами light_marker, которые выводят цвет без освещения.

## Что нужно для сборки

- компилятор с поддержкой C++20 (GCC, Clang или Visual Studio)
- Vulkan SDK, в нём есть glslc для компиляции шейдеров
- CMake 3.20 или новее и Ninja

Библиотеки GLFW, ImGui, vk-bootstrap и VMA скачиваются сами при первой настройке CMake, нужен интернет.

## Сборка

GCC (MSYS2) и Ninja:

```
cmake --preset debug -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++
cmake --build build-debug --parallel
```

Visual Studio:

```
cmake --preset msvc-debug
cmake --build build-debug --parallel
```

Шейдеры из папки shaders компилируются в .spv автоматически во время сборки.

## Запуск

GCC: build-debug/vulkan-starter-app.exe
Visual Studio: build-debug/Debug/vulkan-starter-app.exe

Путь к шейдерам прописан в программе полностью, поэтому запускать можно из любой папки.

## Управление

- правая кнопка мыши над сценой и движение мыши: поворот камеры
- W, A, S, D: движение вперёд, влево, назад, вправо
- E и Q: вверх и вниз
- Shift: двигаться быстрее
- колесо мыши над сценой: угол обзора

Все остальные настройки находятся на панели слева. Ctrl + клик по ползунку позволяет ввести точное число.
Клик по заголовку раздела сворачивает его.

## Файлы

- source/application.hpp: структуры данных для шейдеров (SceneData, ModelData, источники света, вершина визуализации) и проверки их раскладки
- source/application.cpp: код лабораторной (сцена, камера, буферы, наборы дескрипторов, конвейеры, визуализация источников, интерфейс)
- source/math3d.hpp: векторы и матрицы из первой лабораторной
- shaders/blinn_phong.vert и shaders/blinn_phong.frag: шейдеры объектов, во фрагментном шейдере модель Блинна-Фонга
- shaders/light_marker.vert и shaders/light_marker.frag: шейдеры визуализации источников, без освещения
- source/main.cpp и source/graphics_internal.cpp: стартовый код, в graphics_internal.cpp исправлен размер пула дескрипторов ImGui
