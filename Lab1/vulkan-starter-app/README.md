# Лабораторная работа №1. Основы 3D-графики

Вариант 3: параллелепипед. Выполнены задание варианта и дополнительные задания 1-5.

Проект сделан на основе стартового кода https://github.com/vladeemerr/vulkan-starter-app (Vulkan, GLFW, ImGui).

## Что умеет программа

- рисует параллелепипед, длины рёбер и углы между ними меняются в интерфейсе
- переключает проекцию: перспективная или ортографическая
- меняет позицию, поворот и растяжение фигуры
- двигает фигуру по траектории (окружность с волнами, спираль, восьмёрка) и вращает вокруг своей оси, есть пауза, скорость и параметры траектории
- меняет цвет фигуры через палитру
- раскрашивает вершины по их координатам, итоговый цвет = цвет вершины * цвет из интерфейса

## Что нужно для сборки

- компилятор с поддержкой C++20 (GCC, Clang или Visual Studio)
- Vulkan SDK, в нём есть glslc для компиляции шейдеров
- CMake 3.20 или новее и Ninja

Библиотеки GLFW, ImGui, vk-bootstrap и VMA скачиваются сами при первой настройке CMake, нужен интернет.

## Сборка

GCC (MSYS2) и Ninja:

```
cmake --preset debug -DCMAKE_C_COMPILER=gcc -DCMAKE_CXX_COMPILER=g++
cmake --build build-debug --parallel
```

Visual Studio:

```
cmake --preset msvc-debug
cmake --build build-debug --parallel
```

Шейдеры из папки shaders компилируются в .spv автоматически во время сборки.
Если добавили новый шейдер в CMakeLists.txt, нужно заново запустить первую команду.

## Запуск

GCC: build-debug/vulkan-starter-app.exe
Visual Studio: build-debug/Debug/vulkan-starter-app.exe

Путь к шейдерам прописан в программе полностью, поэтому запускать можно из любой папки.

## Как пользоваться

Все настройки находятся на панели слева, разделы пронумерованы так же, как дополнительные задания.
Ctrl + клик по ползунку позволяет ввести точное число.
Клик по заголовку раздела сворачивает его.

## Файлы

- source/application.hpp и source/application.cpp: код лабораторной (геометрия, буферы, конвейер, интерфейс, анимация)
- source/math3d.hpp: векторы и матрицы (перенос, повороты, растяжение, lookAt, проекции)
- shaders/parallelepiped.vert и shaders/parallelepiped.frag: шейдеры
- source/main.cpp и source/graphics_internal.cpp: стартовый код, в graphics_internal.cpp исправлен размер пула дескрипторов ImGui
