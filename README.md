# Компьютерная графика

Лабораторные работы по курсу «Компьютерная графика». Язык C++, графика на Vulkan, интерфейс на ImGui.

## Лабораторные работы

- Lab1: основы 3D-графики, вариант 3 (параллелепипед). Код в папке Lab1/vulkan-starter-app, отчёт в папке Lab1/report.

Как собрать и запустить каждую лабу, написано в README внутри её папки.
